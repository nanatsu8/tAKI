# BGM・効果音の復元

音源ファイルはGitHubリポジトリに含めていません。各配布元の利用条件に従って入手し、次の場所へ配置してください。
この文書のパスはUnityプロジェクト `tAKI/` を基準にしています。

## 配置するファイル

配置先：`Assets/_Project/Audio/Provided/`

| 用途 | 配布元・素材名 | 配置時のファイル名 |
| --- | --- | --- |
| BGM | [OpenTracks「flow」／ゆうり(Yuli Audio Craft)](https://opentracks.com/bgm/detail/9795) | `flow-基本BGM.mp3` |
| アイテム取得 | [効果音ラボ](https://soundeffect-lab.info/)「決定ボタンを押す33」 | `決定ボタンを押す33-アイテム獲得時.mp3` |
| AKIブースト | 効果音ラボ「決定ボタンを押す25」 | `決定ボタンを押す25-AKIブースト.mp3` |
| 障害物接触 | 効果音ラボ「キャンセル4」 | `キャンセル4-障害物接触時.mp3` |
| クリア | 効果音ラボ「歓声と拍手2」 | `歓声と拍手2-クリア時.mp3` |

配布元からダウンロードしたファイルを、表の名前へ変更して配置します。音源のダウンロードやGitHubへの再アップロードは自動では行いません。
利用条件と作者・提供元は [CREDITS.md](CREDITS.md) に記載しています。

## Unityで読み込む

1. 初回は、できればUnityプロジェクトを開く前に5ファイルを配置します。
2. リポジトリ内の同名 `.mp3.meta` はそのまま残します。これにより、既存のAudioClip参照を保てます。
3. Unity 2022.3.62f3でプロジェクトを開き、インポート完了を待ちます。
4. `Assets/_Project/Resources/GameAudio.asset` の5つの音声参照を確認します。
5. 参照がMissingの場合は、Unity上部の **`tAKI > Restore audio references`** を実行します。このメニューはファイル名から5つの参照を再接続し、既存の音量設定を保持します。

すでに音源なしでUnityを開いた場合も、ファイルを配置後に同じメニューで復元できます。5ファイルのいずれかがない場合は復元を中止するため、ファイル名と配置先を確認してください。

## 実行・ビルド

`Assets/_Project/Scenes/Main.unity` を開き、開始待機中のBGM、取得音、AKI音、被弾音、クリア音を確認します。
音源を復元していないクローンでは、BGM・効果音が欠けます。`tAKI > Build Windows` の事前検証も音声参照がそろうまで失敗します。

ローカルに配置したMP3は `.gitignore` により除外されます。`.meta`・`GameAudio.asset` は参照を維持するためGit管理の対象です。
