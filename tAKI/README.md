# tAKI

Unity 2022.3.62f3／URP 14.0.12で制作する、Windows向けの滝のぼりアクションです。
仕様は [GAME_DESIGN.md](GAME_DESIGN.md) を参照してください。

GitHubから取得した場合は、先に [音源の復元手順](AUDIO_SETUP.md) に従ってBGM・効果音を配置してください。MP3とダウンロードした素材原本はリポジトリに含めず、実行に使うモデル・フォントは `Assets/_Project/` に含めています。

## Unityで遊ぶ

1. Unity Hubから、このREADMEと同じ階層のプロジェクトを開きます。
2. `Assets/_Project/Scenes/Main.unity` を開き、Playを押します。
3. Gameビューをクリックし、WASDで開始・移動します。

開始待機画面の **VOLUME** バーを左ボタンでドラッグすると、BGMと効果音の共通音量を調整できます。クリックだけ・キー・ホイールでは変更しません。WASDで開始するとバーは消えます。初期音量は50％で、再挑戦時にも調整した音量を引き継ぎます。
BGMは開始待機中から常にループ再生し、クリア中・再挑戦時も止めずに流し続けます。再挑戦で先頭へ戻りません。クリア時の歓声・拍手はBGMと同時に再生します。

Wは上向きの補助、Sは下向きの補助、A・Dは左右移動です。
流れてくるアイテムを取って上昇し、A・K・Iをそろえると追加のブーストが発生します。
流木に当たると上昇の勢いを失います。下端へ落ちても再挑戦を続けられます。
頂上のsAKIへ到達すると、KurIA／クリア！が表示されます。
クリア後はWASDを一度離し、表示から1.2秒以上経過後に押すと最初から遊べます。

## 調整する

| アセット | 内容 |
|---|---|
| `Assets/_Project/Settings/GameSettings.asset` | 移動、重力、上下速度上限、ゴール高度、ブースト量、スポーン間隔、難易度、被弾 |
| `Assets/_Project/Settings/ItemA.asset` | アケビの出現重み、上昇量、流下速度、色、Prefab |
| `Assets/_Project/Settings/ItemK.asset` | カキの同上設定 |
| `Assets/_Project/Settings/ItemI.asset` | イチジクの同上設定 |
| `Assets/_Project/Resources/GameAudio.asset` | BGM・各効果音、初期音量、BGM・効果音・クリア音の音量バランス |

アイテムは **Item Spawn Distance**（現在4 unit）上下に移動するごとに1個出現します。移動距離は方向転換を含めて累積します。小さくすると移動距離あたりの個数が増えます。単位は実距離です。
これに加え、**Item Timed Spawn Interval**（現在1秒）ごとに1個を上側の画面外へ生成します。プレイ中なら静止中・下降中も追加されます。0にすると時間生成だけを停止します（正の間隔は最小0.1秒）。開始待機・クリア中には生成せず、再挑戦でタイマーをリセットします。種類は共通の重み抽選を使い、全種類の重み0なら追加生成も停止します。
上昇中は画面の上側、下降中は画面の下側へ生成します。カメラ追従後に、実際の表示範囲とプレイヤーの移動面（Z=0）から位置を求めるため、カメラの大きさや画面の縦横比を変えても画面外に配置します。**Item Offscreen Margin**（現在2 unit）は画面端からの余白です。下降先がステージ下端より下になる場合は、上側の画面外へ切り替えます。
開始時のみ、プレイヤーの2 unit上から、画面上端の1 unit手前まで、画面内に高さ2 unit間隔でアイテムを配置します。最初のWASD入力時に1回だけ実行し、再挑戦時も同様です。この間隔は通常のItem Spawn Distanceとは独立しています。
開始後、静止・下降中に取得できるアイテムがなくなった場合は、上側の画面外へ3個を補充します。補充後は距離の累積をリセットします。全種類の重み0なら初期配置と補充も停止します。
障害物は、初めて到達した高度の距離しきい値ごとに1個生成します。下降・静止・既に通過した高度への再上昇では増えません。障害物が消えたり、アイテムが補充されたりしても、この高度の記録は保持し、再挑戦時にリセットします。

| Obstaclesの設定 | 現在値 | 内容 |
|---|---:|---|
| Early Obstacle Distance | 30 | 序盤の生成間隔（unit） |
| Middle Obstacle Distance | 17 | 中盤の生成間隔（unit） |
| Final Obstacle Distance | 9 | 終盤の生成間隔（unit） |

小さくすると移動距離あたりの障害物が増えます。以前の3／1.7／0.9秒から、目安速度10 unit/sで換算した初期値です。Middle At／Final Atで区間の境界を調整します。
障害物は画面上端の2 unit上、またはプレイヤーの **Spawn Ahead + 1** unit上のうち高い側へ生成します。下側には生成しません。

出現確率は各アイテムのSpawn Weightの比率で決まります。
`1 : 1 : 2` は25％・25％・50％です。0の種類は出現せず、すべて0ならアイテム生成が停止します。
Upward Impulseは取得後に保証する上向き速度です。取得後の内部Y速度は `max(Upward Impulse, 現在の内部Y速度)` とし、Max Stored Rise Speedで制限します。実際の移動にはMax Rise Speedを適用します。例えば値が5なら、下降中や上昇速度3では5になり、上昇速度10なら10を保ちます。通常取得では加算しません。
Display ColorはHUDと取得演出に使用し、果物本体の色は対応するMaterialで変更します。

プレイヤーの速度は、Projectウィンドウの `Assets/_Project/Settings/GameSettings.asset` を選び、Inspectorで調整します。

| Inspectorの項目 | 参考初期値 | 調整したときの効果 |
|---|---:|---|
| Horizontal Speed | 5 | 大きいほどA・Dの左右移動が速くなる（unit/s） |
| Gravity | 3 | 小さいほど上昇の勢いが長持ちする。正の値で下向き加速度を指定（unit/s²） |
| Vertical Assist | 1 | 大きいほどWで上昇を維持しやすく、Sで減速・下降しやすくなる（unit/s²） |
| Max Rise Speed | 14 | 実際の上昇速度の上限（unit/s）。現在値はInspectorで確認 |
| Max Stored Rise Speed | 30 | 内部に保持する上昇速度の上限（unit/s）。実効値はMax Rise Speed以上 |
| Max Fall Speed | 1.5 | プレイヤーの落下速度の上限。小さいほどゆっくり落下（unit/s） |
| Set Bonus | 8 | AKI完成時に加算する上向き速度（unit/s） |
| Aki Invulnerability Seconds | 0.8 | AKIブースト後に障害物を壊せる無敵時間（秒） |
| Hit Fall Speed | 1.5 | 被弾直後の下向き速度。Max Fall Speedを超えない（unit/s） |

`ItemA.asset`／`ItemK.asset`／`ItemI.asset` の **Upward Impulse** は、種類ごとの取得後の最低上昇速度です。AKI完成時の **Set Bonus** は、その速度へ引き続き加算します。
上昇を速くしたい場合は、取得時の勢いを変えるUpward Impulseと、最高速度を変えるMax Rise Speedを組み合わせて調整します。
Wだけで登れない挙動を維持するため、Vertical AssistはGravityより小さくしてください。
重力とW/S補助は内部速度へ反映します。例えば実移動上限20・内部上限30では、内部速度が30から20へ減少する間も実際には20で移動します。通常の被弾は内部の勢いも失わせます。
HUDのタイマー下に実際のY速度をm/sで表示します。上昇は正、下降は負です。換算式は `実際のY速度 × Displayed Goal Meters ÷ Goal Height` で、高度表示と同じ単位になります。現在の500 unit／1000mでは20 unit/sが40 m/s、−10 unit/sが−20 m/sです。速度0以下は白、上昇速度が高いほど赤く、移動上限で赤になります。色はHUDのSpeed Low Color／Speed Max Colorで調整できます。

速度表示の下には上昇中の連続取得数を `3 COMBO` のように表示します。取得直前の実際のY速度が正なら1加算し、文字が短く拡大・発光します。同じ種類でも数え、AKI完成時も取得1個分です。停止・下降でリセットし、下降から上昇へ転じる最初の取得は数えません。AKI無敵中の接触では維持します。0・開始待機・クリア時は非表示です。文字色はHUDのCombo Colorで調整できます。

AKIブースト後の0.8秒間は、障害物に触れても減速せず、その障害物を消します。被弾回数も増えません。無敵中に再びAKIを完成させると、その時点から無敵時間を更新します。通常の被弾後の無敵とは別の設定です。
通常の被弾後の無敵時間が終われば、同じ障害物への再接触でも再びペナルティが発生します。通常の接触では障害物は消えず、AKI無敵中の接触で消えます。

アイテムの **Fall Speed** は種類ごとの基準落下速度です。生成時にGameSettingsの **Item Fall Speed Multiplier Min**（初期値1）〜**Item Fall Speed Multiplier Max**（初期値3）の間から倍率を1回抽選し、基準速度に掛けます。例えば基準2.6なら2.6〜7.8 unit/sになります。両方1ならランダム化せず基準速度のままです。開始時・距離・時間・補充の全アイテム生成に適用します。
GameSettingsの **Obstacle Fall Speed** は障害物の落下速度で、このランダム倍率は掛かりません。出現済みの物は生成時の速度を保ち、設定変更は新しい生成から反映されます。

調整はPlay停止中に値を変更してから再生すると比較しやすくなります。これらの設定アセットはPlay中の変更も保持されるため、変更前の値を控えてください。シーン上のオブジェクトへのPlay中の変更は通常、停止すると元に戻ります。
Goal Heightは実際の登頂距離（現在500 unit）、Displayed Goal Metersは頂上での表示距離（現在1000m）です。中間地点の250 unitでは500mと表示します。
Waterfall Widthは滝の幅（現在24 unit、初期実装の2倍）です。移動範囲とアイテム・流木の出現範囲もこの幅に追従します。
Goal HeightとWaterfall Widthを変更した場合、水面・岩壁の土台・ゴールの目印は開始時に調整されます。岩・木の高度はWaterfallのDecoration Height（配置時の頂上高度）、水流の横位置はDecoration Width（配置時の滝幅）を基準に伸縮します。

## 演出を調整する

`Assets/_Project/Resources/GameFeel.asset` を選び、Inspectorで調整します。Mainシーンを作り直す必要はありません。停止後に再度Playすると演出が自動で追加されます。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| Pickup Seconds | 0.22 | 取得の光の輪・サケの伸縮が戻る時間（秒） |
| Pickup Ring Radius | 1.4 | 取得の光の輪の最大半径（unit） |
| Pickup Particles | 18 | 取得位置で弾けるアイテム色の粒数 |
| Fish Stretch | 0.24 | 取得時のサケの縦伸びの割合 |
| Speed Punch Seconds / Scale | 0.15 / 0.16 | 加速したときの数字の拡大時間（秒）と割合 |
| Water Line Count / Alpha | 32 / 0.32 | 高速時の水流線の最大本数と不透明度。本数は再Play時に反映 |
| Boost Color | 金色 | AKIの光・水流線・残光の色 |
| Boost Punch Seconds / Zoom Out | 0.55 / 0.09 | カメラの引きが戻る時間の目安（秒）と引く割合。0で引きを無効化 |
| Boost Trail Seconds | 0.28 | AKIの残光の長さ（秒）。0で残光を無効化 |
| Combo Milestones | 5, 10, 20 | 追加の粒・光の輪・文字を出すコンボ数 |

通常取得では、アイテム色の粒・光の輪・浮かぶ文字・下向きの水しぶきとHUDカードの反応を重ねます。加速時は速度数字が弾み、最高速では赤い光と `^` マークが付きます。左右の水流線は上昇速度に合わせて増えます。

速度の下の細いゲージは、移動上限を超えて保持している勢いです。内部速度20／移動上限20では空、内部25／内部上限30では半分、内部30では満タンになります。取得時にはゲージも光ります。

AKI完成時はA・K・Iの文字がHUDから集まって弾け、カメラが少し引きます。AKI無敵が続く間はサケの光の輪・残光・金色の水流を維持します。移動・取得・無敵時間・BGM・効果音のピッチは既存の仕様を使います。

## Windows版

- ビルド先：`Builds/Windows/tAKI.exe`
- 初回実装の配布用ZIP：`Builds/tAKI-Windows.zip`。展開して `tAKI.exe` を起動します。
- 再ビルド後は、実行ファイルだけでなく `Builds/Windows/` 内のデータ・ランタイム・ライセンスをまとめて再圧縮してください。`Verification/` と `*_DoNotShip/` は配布に含めません。
- Unityメニューの `tAKI > Build Windows` で再ビルドできます。
- 既存のMainシーン、Prefab、調整アセットは再ビルドで作り直しません。
- `tAKI > Prepare game assets` は、存在しない初期アセットを生成するためのメニューです。

## 確認

- `tAKI > Verify gameplay logic` で、出現重み、AKIの状態遷移、速度上限などを確認できます。
- Windows版を `-takiSmoke` 付きで起動すると、入力・物理・取得・被弾・クリアの自動確認を行い、`Builds/Windows/Verification/` に結果と画面画像を保存して終了します。
- `-takiPlaythrough` では、WASDの入力だけでステージを通して遊ぶ確認を行います。確認時間を短縮するため4倍速で進め、結果は `Verification/Playthrough/` に保存します。
- `Builds/build.log` は直近の自動ビルドのログです。
